# Foundation for Africa Empowerment (FAE) Website

A responsive, single-page informational website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website content and structure
- `styles.css` — layout, colors, responsive design and visual styling
- `script.js` — mobile navigation, current year and email contact form behavior

## Run locally
1. Extract the ZIP file.
2. Open the `fae_website` folder.
3. Double-click `index.html` to open it in your browser.
4. For editing, open the folder in Visual Studio Code.

## Contact form note
The contact form uses a `mailto:` link. It opens the visitor's configured email application and does not send or store messages on a server. For a live website, connect a secure form service or backend before relying on form submissions.

## Before publishing
- Confirm the official registration wording and partner organization names.
- Add FAE's approved logo and real programme/community photographs.
- Confirm permission to use partner names and logos.
- Add the organization's official physical address and social media links if available.
- Replace the email-based form with a secure backend or trusted form provider if direct website submissions are required.
- The photographs currently load from Unsplash and require an internet connection.
